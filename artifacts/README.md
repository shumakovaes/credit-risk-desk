# Локальные артефакты

`credit-desk train` создаёт `model.joblib` и `training_report.json` после импорта Berka. Файлы не включаются в Git. Копия результатов выполненного эксперимента хранится в `reports/training-report.json`.

В demo модель не используется. Загружайте только артефакты, обученные вами: joblib/pickle небезопасен для недоверенных файлов.
